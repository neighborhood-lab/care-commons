# Folk Care Branding Guidelines

This document defines the official branding standards for Folk Care.

---

## Product Name

**Folk Care** (two words, title case)

- Use in all marketing materials, documentation, and formal communications
- The space between "Folk" and "Care" is intentional

### Usage Examples

| Context | Correct | Incorrect |
|---------|---------|-----------|
| Product name | Folk Care | FolkCare, Folkcare, folkcare |
| Sentence start | Folk Care is... | Folkcare is... |
| Headings | Welcome to Folk Care | Welcome to FolkCare |

---

## Domain

**folk.care**

- Official website and product domain
- Use lowercase in URLs and technical contexts
- Example: `https://folk.care`

---

## Package Namespace

**@folkcare/**

- Used for npm packages (no space, lowercase)
- Example: `@folkcare/core`, `@folkcare/web`
- This is a technical identifier, not the product name

---

## Tagline

> "Software for the people who care"

Alternative taglines:
- "Shared care software, community owned"
- "Open source home healthcare software"

---

## When to Use Each Form

| Form | When to Use |
|------|-------------|
| **Folk Care** | Marketing, documentation, UI headings, press releases, formal contexts |
| **folk.care** | URLs, domain references, technical docs referencing the website |
| **@folkcare** | Code, package.json, imports, npm references |
| **folkcare** | Database names, file paths, environment variables (when single word needed) |

## Logo Usage

### Primary Logo
- Full color logo for light backgrounds
- White/reversed logo for dark backgrounds
- Minimum clear space: 16px on all sides

### Logo Don'ts
- Don't stretch or distort
- Don't change colors outside approved palette
- Don't add effects (shadows, gradients, etc.)
- Don't place on busy backgrounds without sufficient contrast

## Voice and Tone

### Our Voice Is:
- **Human** - We speak like real people, not corporations
- **Caring** - We prioritize the wellbeing of caregivers and clients
- **Clear** - We avoid jargon and explain technical concepts simply
- **Empowering** - We help people do their best work

### Writing Guidelines:
- Use active voice
- Keep sentences short and scannable
- Address users directly ("you" not "the user")
- Be specific, not vague
