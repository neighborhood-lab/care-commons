## Publishing Steps

For each article:

1. **Open Substack** - Go to https://folkcare.substack.com
2. **Create new post**
3. **Copy article text** from markdown file
4. **Add title/subtitle** from YAML frontmatter
5. **Generate header image** using the `image_prompt` in YAML
   - Option A: Use AI image generator (DALL-E, Midjourney, etc.)
   - Option B: Skip image for now
6. **Schedule or publish**
   - Use `scheduled_date` from YAML
   - Or publish immediately
7. **Share** on Twitter/X, LinkedIn
